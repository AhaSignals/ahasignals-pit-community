# Contributing a reproducible case

Use an issue to describe a finding or integration need. The issue forms request
versions, intended timing, a minimal permitted example and expected behavior.
No access to the private development repository is needed.

Please distinguish a software error from missing evidence or a different research
policy. A date-only availability policy cannot establish a precise historical
acquisition timestamp. An unexpected UNKNOWN is worth explaining, but it is not
automatically a software defect.

Public issues and examples must contain no credentials, personal machine paths,
private URLs or data you cannot redistribute. Use synthetic records where possible.
An optional form checkbox permits a contributor-owned example to become an
MIT-licensed regression test; this permission is not a condition of reporting a bug.

When a fix is released, the issue can link to the public release and describe how
to reproduce the corrected behavior. Please rerun your minimized input and state
whether the issue is resolved. No response-time or integration commitment is implied.

This repository holds support material and public feedback. Released package
source and tests are available from the source distribution linked in the README.
Changes to the checker are developed separately. Pull requests here should concern
these public guides and examples; do not upload private project files.
